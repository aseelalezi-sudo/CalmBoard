## سياسة Dependabot

أضيف تجاهل `version-update:semver-minor` للحزم الثلاث السابقة فقط، مع بقاء تجاهل
الترقيات الرئيسية العام. بذلك تستمر تحديثات patch لهذه الخطوط وبقية مجموعات الاعتماديات،
ويُمنع تكرار ترقية المراقبة غير المتوافقة ضمن الطلبات الأسبوعية العادية. تبقى تحديثات
الأمان وفحوص audit فعالة؛ لا توجد استثناءات تدقيق جديدة. راجع
[مرجع GitHub لإعدادات Dependabot](https://docs.github.com/en/code-security/reference/supply-chain-security/dependabot-options-reference)
قبل تعديل السياسة أو إزالة قيود الترحيل.
