# حالة تطوير CalmBoard والإصدار

آخر تحديث: 2026-11-05. هذا هو سجل الحالة الحالي؛ تقارير M1–M5 أدلة تاريخية
ولا تُستخدم وحدها لإثبات جاهزية النسخة الحالية للإنتاج.

مرجع Git عند بدء العمل: `14922fc951fde0fc83993d3fa4d9270806d4b3d1`.
تؤخذ حالة رفع المصدر ونتيجة CI النهائية من Git وGitHub، ولا يحل التحقق المحلي محلها. نسخة التحقق المحلية تُنشأ
في مجلد مستقل بمصدر وبصمات مسجلة، دون `.env` أو `node_modules` أو مخرجات بناء سابقة.

لا توجد موافقة Production أو Beta شاملة في هذا السجل. الإغلاق المحلي لبند
لا يغيّر بوابات الخدمات الخارجية أو مخاطر الإصدار المفتوحة.

أُغلقت تحذيرات التنقل الداخلي الثلاثة باستخدام Next router، وأصبح lint للويب
يرفض التحذيرات. عولج تعارض webpack/schema-utils بتثبيت webpack 5.112.2 للويب.
نجحت جولة CI محلية جديدة بـ983 اختبارًا والبناء، و18 حالة متصفح بلا retries؛
أما أدلة 125 تكاملًا و8 ترحيلات فتخص الجولة الأمنية السابقة ذات المصدر المسجل.
تفاصيل المصدرين وتصحيح محدد الاختبار فقط بين CI والمتصفحات في [دليل الجودة](./quality-gate.md).

أثبت الفحص الختامي بقاء سجل الترحيلات ومخطط قاعدة التطوير دون تغيير، وصفر
قواعد/Redis/buckets مؤقتة متبقية وصفر أدوار جديدة بعد جولة التكامل المقاسة؛
الخدمات الثلاث بـ200. توجد أدوار اختبار تاريخية غير منسوبة تحتاج جردًا منفصلًا؛
لم تُحذف بالتخمين. الأدلة في `artifacts/r0-final-state.json`.
