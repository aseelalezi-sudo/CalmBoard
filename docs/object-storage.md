# تخزين المرفقات

يستخدم مسار المرفقات تخزينا متوافقا مع S3، بما في ذلك MinIO في بيئة التطوير.

## الإعداد المطلوب

- أنشئ bucket مطابقا لقيمة `S3_BUCKET`.
- اجعل `S3_ENDPOINT` عنوان الخدمة الذي يصل إليه الخادم.
- اجعل `S3_PUBLIC_ENDPOINT` عنوان MinIO أو S3 الذي يستطيع متصفح المستخدم الوصول إليه.
- اضبط CORS في bucket للسماح بطلبات `PUT` و`GET` من أصل `APP_URL`.
- احتفظ بـ `S3_ACCESS_KEY_ID` و`S3_SECRET_ACCESS_KEY` في بيئة الخادم فقط.

لا تخزن قاعدة البيانات روابط مؤقتة؛ تحفظ مرجعا بالشكل `s3://bucket/key`. يصدر الخادم رابط رفع صالحا لمدة 15 دقيقة ورابط تنزيل صالحا لمدة 5 دقائق.

الحد الحالي للملف هو 50MB. أنواع HTML وJavaScript وSVG والملفات التنفيذية غير مسموحة. يظل فحص البرمجيات الخبيثة وحالة `pending/ready/quarantined` بندا لاحقا قبل اعتماد الرفع للإنتاج العام.
